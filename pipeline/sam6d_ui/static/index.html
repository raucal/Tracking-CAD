What the modes mean
RGB only
Locate CAD using masks, visual similarity and appearance. No calibrated camera or depth is required. The score is the mean of similarity and appearance.


RGB-D
Adds depth and calibration to evaluate geometric consistency using the SAM-6D ISM formula. RGB and depth must be aligned.


6D pose · PEM or FoundationPose
Enable Estimate 6D pose to run the selected backend after detection. FoundationPose receives a SAM/FastSAM mask and can track RGB-D recordings. No manual box is needed. The 3D box projects the estimated pose for inspection. Rotation and translation are returned in millimetres in camera coordinates. Requires aligned depth, calibration and CUDA.


Scores are not calibrated probabilities. Matching a single CAD does not establish that it is the only possible class. The first run includes model loading and, for a new CAD, rendering and reference preparation; later runs reuse these caches.
